# Simulator

The simulator is a Vite + React + TypeScript reference implementation of the head-pose cursor math.
It renders a simple 3D head, a face-forward ray, a flat monitor plane, and raw vs. smoothed cursor previews.

## Commands

From the repository root:

```bash
cd simulator
npm install
npm run dev
```

Additional checks:

```bash
cd simulator
npm run test
npm run build
npm run lint
```
